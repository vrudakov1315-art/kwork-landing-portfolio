# Пульс

Демонстрационный SaaS-лендинг рабочего пространства для команд. Интерфейс
панели собран из HTML и CSS; изображения интерфейса и логотипы существующих
сервисов не используются.

## Возможности

- переключение месячной и годовой цены хранится только в DOM;
- четыре FAQ-ответа реализованы нативными `details`;
- форма доступа валидируется и подтверждается локально без сетевого запроса;
- адаптивная сетка, видимые состояния фокуса и поддержка `prefers-reduced-motion`.

## Локальный просмотр

Из каталога `portfolio/kwork-landings`:

```powershell
npm install
npm test -- tests/puls.spec.js
```

Страница доступна по адресу `/sites/puls/index.html` на локальном сервере
проекта.
