# «Север» — концепт лендинга кофейни

Одностраничный учебный проект: семь секций, адаптивная навигация и
демонстрационная форма бронирования без отправки данных.

## Запуск

Из каталога `portfolio/kwork-landings`:

```powershell
npm test -- tests/sever.spec.js
```

Страница доступна по адресу `/sites/sever/index.html` на локальном сервере
проекта.
