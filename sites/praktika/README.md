# «Практика» — демонстрационный лендинг курса

Одностраничный учебный проект курса по визуальным презентациям. На странице семь
секций, доступный аккордеон программы и демонстрационная форма записи без отправки
данных.

Профиль «Лера Миронова» — **вымышленный персонаж для демонстрации**. Имя,
биография, цитата и профессиональный опыт не описывают реального человека.
Фотография используется только как иллюстративный образ.

## Запуск

Из каталога `portfolio/kwork-landings`:

```powershell
npm test -- tests/praktika.spec.js
```

Страница доступна по адресу `/sites/praktika/index.html` на локальном сервере
проекта.
